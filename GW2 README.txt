Общие инструкции

Если у вас уже установлен zapret, то:
1) отключите его
2) запустите файл service
3) нажмите 2 - Remove Services, далее Enter
4) теперь выбираем 10 - Run Diagnostics, далее Enter
4) Вам предложат очистить кэш Discord'a, нажмите Y и Enter

Теперь шаги и для тех, у кого был установлен, и для тех, кто ставит впервые:
1) распакуйте архив в новую папку (или используйте дефолтную из архива)
2) запустите файл Service
3) выберите 11 - Run Test. Дождитесь окончания теста, в конце которого напишут подхоядщий для указанных ресурсов ALT для вас. Например, ALT11. Конкретно для ГВ2 эта функция не распространяется
4) теперь в этом же меню Service выбираем 1 - Install Service и указываем тот, что вам указали при тесте.

После этого стратегия будет автоматически запускаться при старте ПК.




При возможных проблемах с соединением в ГВ2:

1) в консоли (cmd) от администратора должна быть единожды введена команда:
netsh interface tcp set global timestamps=enabled

2) перед запуском сервиса/батника там же, в консоли, прописать команду:
ipconfig /flushdns

3) в свойствах ярлыка игры (в том числе Steam) не должно быть лишних настроек. В частности:
-clientport 80
или
-clientport 443

Имеются случаю, где некоторым ПОМОГАЕТ наличие -clientport 6112 в свойствах ярлыка (это стандартный порт, используемый игрой). При наличии проблем с соединением есть смысл попробовать добавить данную приписку.

Запрет должен быть запущен от имени администратора и оставаться свернутым на рабочем столе (желтый замочек).
Также бывали случаи, когда Запрет не работал, если запускать непосредственно его через файл .bat, но работал, если установить его через сервис.

В пути запрета не должно быть кириллицы и пробелов.

На работу могут влиять установленные в системе ПК или роутера ДНС (стоит попробовать Гугловские 8.8.8.8/8.8.4.4 или 1.1.1.1/1.0.0.1 от Cloudflare).




Информация для разбирающихся (или кто хочет начать что-то понимать):

Guild Wars 2 использует три порта для своей работы:
80 порт для обновлений клиента и лаунчера;
443 порт для внутриигровых встроенных функций браузера (аукцион, шоп, Wizard Vault);
6112 порт для самой игры (загрузка на персонажей в локации).

Стратегии для этих функций находятся в самом начале файлов .bat (строки 17-20).

Помимо измененных вариаций .bat имеются дополнительные файлы, которые отличаются следующим:
1. general (ALT11)_AltFake,AltWizardVault  - имеет другой фейк для обхода блока Амазоновских серверов (самой игры) и другую стратегию для обхода аукциона и Wizard Vault.
2. general (ALT11)_AltGW2,noWizardVault - имеет другую стратегию обхода Амазоновских серверов (самой игры) и в ней отсутствует стратегия для обхода аукциона и Wizard Vault (т.к. у некоторых они работают и так, не блокируются провайдеров/ ТСПУ).
3. general (ALT11)_AltGW2 - имеет другую стратегию обхода Амазоновских серверов (самой игры), данная стратегия так же отличается от стратегии в п.2.
4. general (ALT11)_AltGW2+AltFake - то же самое, что и верхний вариант, но использует другой фейк для обхода игры.
5. general (ALT11)_killproof - помимо стандартных стратегий имеет строчку для работы сайта killproof.me. Для рейдеров и посетителей страйков/данжей.
6. general (ALT11)_killproof-test - имеет другую, тестовую стратегию для работы аукциона и Wizard Vault относительно п. 5.
7. general (ALT11)_KP - то же самое, что верхний вариант, но использует стратегию для обхода сайта killproof.me и для обхода внутриигрового аукциона и Wizard Vault вместо стандартного для них варианта.
8. general (ALT11)_NoIPSet - стандартный вариант, но не ссылается на блокнот с IP-адресами Амазона. В итоге запрет пускает ВЕСЬ траффик по игровому порту через себя. На случай, если где-то могут попасться айпишники, которых нет в списках (крайне малая вероятность, но никогда не равняется нулю).
9. general (ALT11)_noWV - стандартный вариант, но без стратегии для обхода аукциона и Wizard Vault (для тех, у кого они работают и так).
10. general (ALT11)_TEST_GW2 - другая относительно всех верхних стратегия только для ГВ2.

lists\list-general-user.txt содержит в себе основные сайты с ресурсами по ГВ2, которые часто не работают без запрета.
lists\gw.txt содержит в себе IP-адреса серверов ГВ2 (AmazonAWS).
